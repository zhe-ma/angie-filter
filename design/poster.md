# 大片

这里说的海报质感，是电影宣传片成片的配色和质感：阴影偏青，肤色和灯光偏暖，高光轻轻滚落，夜景灯光有一圈暖晕。它仍然是一款配方，不新开渲染方案。

界面名字用「大片」。叫「海报」会让人以为是印刷品或色调分离。

## 结论

运行时仍是立方体，然后走已经在用的 `FilmFinish`：肤色、肩部、光晕，再加上细颗粒和一点暗角。预览、成片和缩略图不用改调用点。

配色不能靠全局色温。其他配方仍是整张图一起冷或一起暖。大片在 `Tools/BakeColorCubes.swift` 的 `trailerSplit` 里按亮度和色相改格子，再烤进 `ColorCubes/trailer.acube`。手机上每帧仍只查这张立方体，然后走 `FilmFinish`。目录 id 是 `trailer`，放在「电影」分类，名称是「大片」。

不做色调分离，也不做网点、纸纹。那些和宣传片无关。也不要再丢一张来历不明的 LUT。目录里已经有三款容易混在一起，这一款和它们都不一样：

| | 电影 | 800T、灯光 500 | 新锐「电影」 | 大片 |
| --- | --- | --- | --- | --- |
| 实际是什么 | Eterna。低对比，颜色收着，给后期留余地 | 灯光电影胶片。夜景，光晕很重 | 一张 LUT，带一点光晕 | 宣传片已经做完的调色 |
| 颜色 | 发灰 | 偏钨丝灯的暖 | 跟这张图走 | 阴影青，肤色和高光暖 |
| 质感 | 几乎没有光晕 | 光晕 0.35，粗颗粒 | 光晕 0.22，没有颗粒滑杆 | 光晕大约 0.24，细颗粒 |

清晰度只给一点。宣传片的质感来自影调、分色和灯光的晕，不来自把边缘抠硬。

## 画面上长什么样

```mermaid
flowchart LR
  src["转正后的图"] --> cube["立方体<br/>阴影青，肤色暖"]
  cube --> skin["肤色只轻轻收"]
  skin --> tone["高光滚落"]
  tone --> halo["暖光晕"]
  halo --> grain["细颗粒、轻暗角"]
  grain --> mix["按强度溶回原图"]
```

- 暗部和蓝天偏青。树不要鲜艳那种纯绿，往青这边靠一点。
- 人脸、暖色灯光、夕阳留在橙色里。脸在阴影里也不能被染青。
- 黑色有密度，但留一点层次。褪色只用一点点，不把画面抬成灰片。
- 白衣服和灯有肩部，灯周围是已经做好的暖光晕，比 800T 轻。
- 细颗粒铺得很淡。暗角只把四边收住。

## 烘焙时多写的颜色

全局对比、饱和先做，幅度都不大。然后按每个格子自己的亮度和色相改，再写入立方体。

- 亮度低的格子：减一点红，青和蓝抬一点。这是阴影和暗背景。
- 蓝色相：再往青推一截。天空和冷色环境走这里。
- 绿色相：往青靠，不要往鲜艳的绿推。
- 橙色相：无论亮暗，都往暖推，饱和留住。脸在中间调，不能等它变成高光才变暖。
- 高光：红抬一点，蓝收一点。灯和皮肤高光是暖的。

幅度要小。推重了就是另一张青橙网图，人脸会脏，天空会假。和 800T 的差别是：800T 整张偏钨丝灯，大片是冷暖同时在。

## 目录参数

放进「电影」。id 用 `trailer`，名称「大片」。

| 项 | 目录 | 为什么 |
| --- | --- | --- |
| 对比 | 1.14 | 比电影（0.86）紧，不到鲜明那种数码硬对比 |
| 饱和 | 1.06 | 颜色靠分色，不靠整体加饱和 |
| 色温 | 6000 | 全局几乎中性，冷暖交给分色 |
| 清晰度 | 0.2 | 只加一点立体感 |
| 褪色 | 0.06 | 黑位还在，暗部不是死黑 |
| 肩部 | 0.2 | 高光滚落，宣传片的灯不裁成白块 |
| 光晕 | 0.24 | 介于新锐「电影」和 800T 之间。调节里会出现「光晕」 |
| 肤色 | 0.15 | 只挡住红衣服被推爆。再高会把宣传片要的暖肤色洗掉 |
| 颗粒 | 0.16，细板 | 有胶片的质地，不是新闻卷的粗粒 |
| 暗角 | 0.4 | 和电影那款同一档，四边收住 |

调节仍是现在这套：强度、褪色、清晰度、颗粒、暗角，以及光晕。

验收用原来的六个场景，并和电影、800T 并排：

- 肤色是暖的，不是橙块，也不是青的。
- 蓝天和暗背景偏青，和脸的暖色同时在。
- 红衣服还是红的，不和肤色糊成一种橙。
- 夜景灯光有暖晕，比 800T 收敛。
- 白衣服高光有层次。绿植不发鲜艳那种纯绿。
